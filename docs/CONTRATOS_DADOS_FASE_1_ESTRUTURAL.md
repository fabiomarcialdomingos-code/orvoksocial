**Escopo ratificado em 22/09/2026:** preparação estrutural apenas. Este contrato acompanha `prisma/schema.prisma` e a migração versionada; não é implementação de jornada, cálculo, API ou tela. O catálogo de perguntas reais permanece vazio. Dados de teste, quando usados, devem ser efêmeros e identificados como fixture.

**Invariantes para serviços futuros:** verificar em transação no backend que o consentimento `BE_PREDICTED` está ativo, que `AnswerVersion.subjectId=targetId`, `selfAnswerVersion.subjectId=predictorId`, que as versões das perguntas coincidem e que o gabarito foi registrado antes do snapshot; impedir resultado previamente revelado. O schema impede órfãos e opção de versão errada, mas não substitui essas verificações temporais/de autorização. Nenhuma regra de retenção ou exclusão irreversível foi incorporada, pois a política jurídica ainda não foi aprovada. A revogação é registrada, mas serviços para bloquear novas previsões e suprimir exposição pertencem a fase posterior.

**Governança:** migrações futuras adicionam resultados, CalculationRun, métricas e algoritmos sem reescrever snapshots. O enum de evidência é estrutural; limites oficiais são documentados na V2 canônica, não implementados aqui. Backup/restore e direitos de dados precisam de contrato jurídico e testes antes de usuários reais. A inexistência das 12 perguntas é um bloqueio de publicação do catálogo, não licença para inventar conteúdo.
